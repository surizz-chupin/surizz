# 溯日社区论坛系统

## 项目概述

溯日社区是一个基于PHP+MySQL开发的社区论坛系统，主打简洁、高效、安全的用户体验。系统支持用户注册登录、帖子发布、评论互动、板块分类等核心功能。

**品牌标语：溯本求源，共筑思想栖息地**

## 技术栈

- 前端：HTML5, CSS3, JavaScript (ES6+)
- 后端：PHP 7.4+
- 数据库：MySQL 5.7+
- 架构：原生PHP开发，无框架依赖

## 功能特性

### 核心功能
- 用户系统（注册/登录/个人中心）
- 板块分类管理
- 帖子发布与管理
- 评论互动系统
- 点赞/收藏功能
- 搜索功能
- 响应式设计

### 安全特性
- 防止SQL注入
- 防止XSS攻击
- 密码加密存储
- 用户权限管理

## 部署指南

### 环境要求
- Web服务器：支持PHP 7.4+ 和 MySQL 5.7+
- PHP扩展：pdo, pdo_mysql, json, session
- 数据库：MySQL 5.7+

### 安装步骤

1. **上传文件**
   将 `htdocs` 目录下的所有文件上传到您的虚拟主机网站根目录

2. **创建数据库**
   - 登录MySQL数据库管理面板
   - 创建新数据库（如：suri_forum）
   - 执行 `database.sql` 文件中的SQL语句创建表结构

3. **配置数据库连接**
   - 编辑 `includes/config.php` 文件
   - 修改以下配置项：
     ```php
     define('DB_HOST', 'localhost');      // 数据库主机
     define('DB_USER', 'your_username');  // 数据库用户名
     define('DB_PASS', 'your_password');  // 数据库密码
     define('DB_NAME', 'suri_forum');     // 数据库名
     ```

4. **设置文件权限**
   - 确保 `uploads` 目录可写（755或777权限）
   - 确保 `images` 目录可写（755或777权限）

5. **访问网站**
   在浏览器中访问您的网站域名，即可开始使用

### 初始数据

- 默认管理员账户：`admin`
- 默认密码：`password` (请登录后立即修改)
- 初始板块：技术交流、生活分享、资源互助

## 使用说明

### 用户操作流程

1. **注册账户**
   - 点击"注册"按钮
   - 填写用户名、邮箱、密码
   - 验证后完成注册

2. **登录系统**
   - 点击"登录"按钮
   - 输入用户名/邮箱和密码
   - 登录后可发布内容

3. **发布帖子**
   - 登录后点击"发布"按钮
   - 选择板块、输入标题和内容
   - 点击"发布帖子"

4. **浏览内容**
   - 首页显示热门、最新、精华帖子
   - 点击板块可查看特定分类内容
   - 支持关键词搜索

### 管理员功能

- 后台管理：管理员账户具有帖子管理权限
- 内容审核：可审核、删除不当内容
- 用户管理：可管理用户账户
